# DiceLab Support

## Start here

Before contacting support:

1. Read [`docs/troubleshooting.md`](docs/troubleshooting.md).
2. Confirm the problem still occurs on the latest release or current `main` branch.
3. Search existing GitHub issues for the same symptom.
4. Collect the DiceLab version, operating system/browser, exact dice expression, and concise reproduction steps.

## GitHub

Repository: <https://github.com/sanskarIN/dicelab>

Use GitHub issues for reproducible bugs and feature requests that can be discussed publicly. Please do not put secrets, private files, or sensitive personal information in an issue.

## Security reports

Potential vulnerabilities should follow [`SECURITY.md`](SECURITY.md) and should not be disclosed through a public exploit report.

## What to include in a bug report

- DiceLab version or commit SHA;
- platform and version;
- web or desktop build;
- exact expression, if relevant;
- expected behavior;
- actual behavior;
- minimal reproduction steps;
- screenshots or logs only when they do not expose sensitive information.
