## Important continuation rules

- Keep generated lockfiles package-manager-generated.
- Keep the renderer capability narrow; Rust-side filesystem use is not a reason to grant broad renderer filesystem access.
- Keep Android provider URIs behind native `FilePath` abstractions.
- Keep iOS security-scoped selected-file lifecycle explicit.
- Keep service-worker registration production-only and disabled in Tauri runtimes.
- Keep PWA caching same-origin and preserve generated-runtime asset precaching.
- Preserve the real-browser server-offline reopen test.
- Keep probability insight/comparison code consuming guarded exact distributions.
- Keep preset sharing separate from full backup state.
- Preserve pre-read size checks for backup and preset imports.
- Keep user-visible native/preset/backup failures localized and free of private raw paths/URIs/errors.
- Keep accessibility policy focused on durable high-value invariants; manual accessibility review remains release evidence.
- Treat configured CI/tests as implementation, not proof of a passing candidate.
- Never commit signing credentials, Android keystores, Apple certificates/private keys, provisioning secrets, or store API credentials.
- Do not call unsigned validation artifacts store-ready.
- Keep README, changelog, roadmap, accessibility guidance, release blockers, release evidence, code/data references, and this handoff synchronized with real behavior.
